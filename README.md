# Ветер между мирами

Неофициальная фанатская визуальная новелла на русском языке. Старик засыпает над книгой и во сне проживает тринадцать жизней — по одной на каждый мир Хаяо Миядзаки. В финале он возвращается в комнату, где жена спрашивает: «Дорогой, что случилось?»

## Запуск

```bash
cd wind-between-worlds
python3 -m http.server 8080 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8080/` в браузере. Для Android можно открыть тот же адрес в локальной сети или установить игру как PWA: после первого визита все основные файлы кэшируются и игра работает без сети.

## Что внутри

- Пролог, 13 глав, финальный «Стеклянный сад» и пять концовок.
- Два эха в каждом мире: тихий разговор и ночная страница-письмо.
- Четыре выбора в каждой главе, осколки памяти и разные финалы.
- 30 аниме-портретов с мягкими масками, выражениями, слезами, румянцем, ветром и искрами.
- 13 аниме-фонов: официальные кадры, пейзажи и фоновые рисунки Studio Ghibli.
- Процедурная музыка и звуки без внешних аудиофайлов — отдельная тема для каждого мира.
- Офлайн-режим через service worker.

## Отладка

- `?scene=conan&at=12&nosw=1` — открыть сцену на нужной строке без service worker.
- `?ending=true` — открыть концовку.
- `window.__VNW` — состояние, сцены, концовки и функции `playScene`, `startNew`, `showEnding`.

## Атрибуция

Это некоммерческий фанатский проект. Права на персонажей и исходные аниме принадлежат их правообладателям. Фон меню — коллаж из открытого доступа; финальный кадр — фанатская иллюстрация из открытого доступа; фоны тринадцати миров — официальные кадры, пейзажи и фоновые рисунки из фильмов Studio Ghibli (в основном Ghibli Wiki / ghibli.fandom.com). Портреты-вырезки персонажей собраны из официальных кадров, Ghibli Wiki (ghibli.fandom.com), Lupin Wiki (lupin.fandom.com), кадра citaty.info (Кларисса) и постера Кинопоиска (Конан и Лана). Иллюстрации юного героя и пожилой пары предоставлены автором проекта. Музыка синтезируется в браузере и не использует записи из аниме.
